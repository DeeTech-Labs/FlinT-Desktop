# Локализация JSON

Формат каталогов использует словари `contexts` PixelStudio и языковые пакеты доменов Rebit. Генерация `.ts` / `.qm` не требуется.

Каждый `translations/<language>/` содержит:

- `meta.json`: `language`, `name`, `author`, `contributors`.
- `common.json`: оболочка, навигация и общие элементы.
- `overview.json`: обзор и USB-подключение.
- `device.json`: телеметрия и сведения об устройстве.
- `diagnostics.json`: интерфейс USB-логов.
- `session.json`: сообщения служб устройства и ошибки.

Пример пакета страницы:

```json
{"contexts": {"DeviceHero": {"CONNECTED VIA USB": "ПОДКЛЮЧЕНО ПО USB"}}}
```

Контексты соответствуют имени файла QML для `qsTr()` и классу C++ для `tr()`. Сохраняйте `%1`, `%2` и другие подстановки. Базовый язык интерфейса — английский: исходные строки QML/C++ и ключи `en` английские; `ru` содержит переводы. Оба каталога покрывают каждый ключ. Новые пакеты обнаруживаются рекурсивно при конфигурации и встраиваются в исполняемый файл. Тесты запрещают дубликаты ключей внутри языка. Русский канонический язык документации не меняет эти правила интерфейса.

Язык можно менять во время работы; выбор сохраняется через QSettings. При первом запуске используется доступный системный язык, иначе английский. Привязки QML переводятся без перезапуска; существующие записи логов сохраняют язык момента записи.

Пользовательские языки и переопределения имеют ту же структуру в `QStandardPaths::AppDataLocation/translations/<language>/`. Для нового языка добавьте `meta.json` и нужные пакеты страниц; для его обнаружения перезапустите приложение. Пользовательские строки перекрывают встроенные, отсутствующие берутся из английского и затем исходного текста. Некорректный JSON игнорируется.

Каталог данных следует соглашениям Qt: XDG data на Linux, Application Support на macOS, AppData на Windows. Проверка покрытия, подстановок и дубликатов: `python3 -m unittest discover -s tests -v`.
