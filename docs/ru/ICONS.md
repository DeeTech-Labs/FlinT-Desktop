# Иконки интерфейса FlinT

Оригинальные линейные SVG-иконки проекта размером 24×24. Каждый файл — самостоятельный ресурс в `assets/icons/`.

Для загрузки используйте `AppIcon` с соответствующим Qt-ресурсом `qrc:/icons/<name>.svg`. Qt применяет монохромный оттенок штатным API иконок. Приложение не генерирует SVG-разметку и пути во время работы.

Иконки входят в библиотеку визуальных ресурсов Flare; при изменениях сохраняйте единый размер и стиль. [Архитектура](ARCHITECTURE.md), [сборка и подключение ресурсов](BUILD.md).
