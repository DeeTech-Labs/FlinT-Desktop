# FlinT Desktop

Десктопное приложение **DeeTech Labs** для работы с часами **Spark** и будущими
моделями устройств на прошивке [FlinT OS](https://github.com/DeeTech-Labs/FlinT-OS).

## Статус

Начальный каркас проекта: запускаемое окно на Qt6, CMake и исходники C++/QML.
Обнаружение устройств, подключение, синхронизация времени и управление часами
пока не реализованы. Прошивка развивается в отдельном репозитории FlinT OS.

## Стек

- C++17 и Qt 6.5 или новее.
- Qt Quick / QML и Qt Quick Controls 2 — интерфейс.
- CMake 3.21 или новее — сборка.
- Целевые платформы: Linux, Windows и macOS.

## Сборка

Установите Qt6 с модулями Quick и Quick Controls 2, CMake и компилятор C++17.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
./build/flint_desktop
```

Если Qt установлен вне системного пути, передайте
`-DCMAKE_PREFIX_PATH=/path/to/Qt/6.x/gcc_64` при конфигурации. Для Qt Creator
откройте `CMakeLists.txt` и выберите комплект Qt6.

При использовании многоконфигурационного генератора (например, Visual Studio)
собирайте с `--config Debug`. Путь к приложению зависит от платформы:
`build/Debug/flint_desktop.exe` в Windows или `build/flint_desktop.app` в macOS.
Команда запуска выше предназначена для Linux.

## Структура

## Направление разработки

Первое поддерживаемое устройство — Spark. Логику приложения следует строить
вокруг протокола FlinT OS и возможностей устройства, чтобы добавление новой
модели не требовало переписывать интерфейс или транспорт.

Ближайшие задачи:

- Обнаружение устройств и подключение через USB Serial/JTAG.
- Синхронизация времени с ПК по протоколу FlinT OS.
- Получение модели и доступных возможностей устройства.
- Управление настройками, циферблатами и обновлением прошивки по мере
  появления соответствующих команд в FlinT OS.

Текущий протокол синхронизации описан в `docs/USB-TIME.md` исходников FlinT OS.
